# 摩斯电码

> 对应 UI：左侧「趣味 / 古典编码」→ `摩斯电码`。所属：趣味编码族。

## L1 速查

**是什么**：用「点 `.`」和「划 `-`」表示字母数字的电报编码（ITU-R M.1677）：字符之间空格，单词之间 ` / `。

**参数表**：无参数。

**最小示例**：

```
输入：SOS
点「编码」→ 输出：... --- ...
```

## L2 详解

**操作全流程**：
1. 左侧选 `摩斯电码`；
2. 粘 `.` `-` 串点「解码」；反向把文字转电码；
3. 分隔符不规范时先手工整理：连续空格可能代表词间隔，单空格是字符间隔。

**算法原理**：每个字母对应 1–4 个点划，数字固定 5 个，标点 5–6 个。本工具字符间用一个空格，词间用 ` / `；编码时遇到不认识的字符原样保留，解码时未知 token 也原样保留，不静默丢字。

**常见坑**：
1. **空格含义有两级**：一个空格是字符间隔，` / ` 是词间隔。全部当字符间隔会把 `HELLO WORLD` 解成一长串无空格文本。
2. **`A`/`B` 与 `.`/`-` 的替代写法**：有些题用 `A` 表示点、`B` 表示划（中文记忆法），本工具在输入不含标准点划时会自动按这个规则尝试；但混用两套符号会解错。
3. **数字与字母共用点划串**：`....` 是 `H`，`.....` 是 `5`，长度差一个就换字符；抄写时漏一个点很常见。
4. **标点不在标准表里就没有唯一答案**：`@` `$` 这些扩展符号各家定义不同，遇到解不出的 token 先查题目给的表。

**真题案例**：暂无已核实案例。
