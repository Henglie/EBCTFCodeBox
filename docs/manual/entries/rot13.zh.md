# ROT13

> 对应 UI：左侧「趣味 / 古典编码」→ `ROT13`。所属：ROT 移位族。

## L1 速查

**是什么**：把每个英文字母向后移 13 位的替换密码。因为 26 个字母移两次回到原位，所以加密和解密是同一个操作（自反）。

**参数表**：无参数。

**最小示例**：

```
输入：HELLO
点「编码」→ 输出：URYYB
```

## L2 详解

**操作全流程**：
1. 左侧选 `ROT13`；
2. 粘文本，点「编码」或「解码」都可以（结果相同）；
3. 只处理 A–Z / a–z，数字、符号、空格原样保留。

**算法原理**：`c → (c - 'A' + 13) mod 26`，大写管大写、小写管小写，非字母不动。13 是 26 的一半，所以变换两次回到原文。

**常见坑**：
1. **只有 13 是自反的**：ROT5（数字）、ROT18、ROT47 都不是 26 的一半；ROT47 在 94 个可打印字符里移 47，也自反，但作用域完全不同。
2. **ROT13 不处理数字和中文字符**：`flag{123}` 变换后是 `synt{123}`，花括号和数字不变——若结果里符号也变了，说明用的是别的 ROT。
3. **和凯撒移位不是一回事**：凯撒是任意位移（1–25），密钥是位移量；ROT13 只是位移固定为 13 的特例。
4. **大小写必须分别处理**：把大小写混在一个 52 字符表里移位会得到错误结果。

**真题案例**：暂无已核实案例。
