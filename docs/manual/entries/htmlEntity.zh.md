# HTML 实体

> 对应 UI：左侧「文本 / 传输编码」→ `HTML 实体`。所属：文本传输编码族。

## L1 速查

**是什么**：把 `<` `>` `&` 等在 HTML 里有特殊含义的字符写成 `&lt;` `&#60;` 这类转义形式。XSS 题和网页源码里最常见。

**参数表**：无参数（编码与解码都是全自动识别）。

**最小示例**：

```
输入：<a>&
点「编码」→ 输出：&lt;a&gt;&amp;
```

## L2 详解

**操作全流程**：
1. 左侧「文本 / 传输编码」→ `HTML 实体`；
2. 粘含 `&...;` 的文本点「解码」；
3. 编码方向自动把 5 个危险字符转成命名实体（`&` `<` `>` `"` `'`）。

**算法原理**：两种写法——命名实体（`&amp;` `&lt;`）和数字实体（十进制 `&#60;` 或十六进制 `&#x3C;`）。数字实体指向字符的 Unicode 码点，所以任何字符都能这样写；解码时两种都认。

**常见坑**：
1. **`&` 必须最先转义**：如果先转 `<` 得到 `&lt;`，再转 `&` 就会把刚生成的 `&` 又变成 `&amp;lt;`，出现双重转义。
2. **`&#39;` 与 `&apos;` 不是一回事**：`&apos;` 是 XML 实体，HTML4 里不认；本工具输出用 `&#39;`。
3. **数字实体可以是十进制或十六进制**：`&#102;` 和 `&#x66;` 都是 `f`。只按 `&#x` 去识别会漏掉十进制形式。
4. **分号不能省**：`&lt` 少了 `;` 在严格解析里不是实体，会被当字面文本；浏览器的容错行为不能当作标准。
