# StegSolve · 首帧通道总览

> 对应 UI：`StegSolve` 工具栏「帧 / 通道总览」→「通道变换」页签。所属：集合工具 · 总览子功能。

## L1 速查

**是什么**：把 42 个通道 / 位平面变换一次铺成缩略图墙，用于快速扫一眼「哪张变换看起来有东西」。**42 张全部基于首帧**（动画的第 1 帧），与当前选中的帧无关，也**不产出任何文件**。

**参数表**：

| 参数（UI 名） | 类型 | 默认 | 取值说明 |
|---|---|---|---|
| 「动画帧 (N)」页签 | 页签 | 帧数 > 1 时默认 | 列出全部合成帧，每格标 `帧 i` 与 `宽×高` |
| 「通道变换 (42)」页签 | 页签 | 帧数 = 1 时默认 | 42 个变换的缩略图，状态栏写明「基于首帧」 |
| 缩略图 | 图像 | — | 最长边限制在 168×120 盒内、最近邻缩放（4×3 图得 160×120） |
| 点击格子 | 按钮 | — | 跳回主视图并定位到该帧 / 该变换 |
| 放大（格子右上） | 按钮 | — | 在图像查看器里看原尺寸 |
| 「导出全部 ZIP」 | 按钮 | — | 与工具栏「批量导出帧/通道」是同一个函数，产物见《StegSolve · 全帧导出》 |

**最小示例**：

```
输入：anim4.png（APNG，4 帧，4×3）
操作：帧浏览里选到第 3 帧 → 点「帧 / 通道总览」→ 切「通道变换 (42)」
观察：状态栏「42 个通道变换（基于首帧）」；首格「原图」缩略图 160×120
判据：该缩略图与第 1 帧一致，与当前选中的第 3 帧不同
```

## L2 详解

**操作全流程**：
1. 载入图像后点工具栏「帧 / 通道总览」，弹出对话框，顶部两个页签分别写 `动画帧 (N)` 与 `通道变换 (42)`；
2. 帧数大于 1 时默认停在「动画帧」，单帧图默认停在「通道变换」；
3. 通道页滚动浏览，缩略图按视口懒加载（没滚到的格子先不算像素，滚到才算，避免大图卡死）；
4. 点格子回到主视图对应位置；点「放大」进图像查看器看原尺寸；
5. 需要文件时用「导出全部 ZIP」——它导出的是全帧 + 42 通道的整包，不是「首帧 42 张」单独打包。

**42 个变换的顺序**（与主视图左右切换的顺序完全一致）：原图、颜色反转(XOR)、Alpha 位平面 7→0、Red 位平面 7→0、Green 位平面 7→0、Blue 位平面 7→0、完整 Alpha / Red / Green / Blue、随机颜色映射 1/2/3、灰度位(R=G=B)。

**为什么固定用首帧**：总览的取图函数是「帧 → 当前帧；通道 → 对首帧做变换」。首帧是载入时就确定的那一幅，通道结论因此稳定；换帧只影响「动画帧」页签与主视图，不会让 42 张图换底图。这也是最容易误读的地方：**先在第 3 帧上看到异常，再打开通道总览，看到的仍是第 1 帧的通道**。

**实测证据**（4 帧 4×3 动图，选中帧 = 3 时开总览）：
- 页签文案 `动画帧 (4)` / `通道变换 (42)`，帧页 4 格、通道页 42 格，状态 `共 4 帧` 与 `42 个通道变换（基于首帧）`；
- 通道首格（原图）缩略图 160×120：全部不透明样本与**首帧**逐像素一致（0 处不符），与**选中第 3 帧**有 5 处不同；
- 帧页第 3 格缩略图与第 3 帧最近邻缩放逐像素一致。

**常见坑**：
1. **总览本身不下载**：42 张缩略图只存在于画布里，没有「保存当前缩略图」；要文件只能走批量导出，且拿到的是整包。
2. **缩略图不是判据**：最长边被压到 168×120，位平面里 1 像素宽的载荷会被邻居覆盖。缩略图只用来「找可疑」，下结论必须点开放大或直接导出。
3. **随机颜色映射不可复现**：映射 1/2/3 每次渲染使用随机参数，同一张图两次打开总览外观可能不同；不要用截图对比当作变换结果。
4. **单帧图默认不在帧页**：`动画帧 (1)` 页签存在但不在前台，别以为「没有帧页」。
5. **缩略图墙的懒加载**：滚动很快时部分格子可能仍是空白画布，等一拍再判断。
