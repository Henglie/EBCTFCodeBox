## 附：op 条目写作规范

1. 每个 op 一条标准条目（格式见 `样章-条目模板.md`），分 L1 速查 / L2 详解两级，
   高频 op 加深 L3。
2. 全部示例必须可复现；参数描述与 UI 实际一致；不写"支持一切"式空话。
3. 真题引用标注来源；无法核实的题目不标"真题"。
4. 文中术语与主 README / 应用内 i18n 保持一致（如「一把梭」「配方链」「宽松判定」）。

## 附：分期交付节奏（建议）

- 每期投入 1–2 个分类（约 20–80 个 op），完成 L2 草稿 → 评审 → 定稿。
- 卷一（入门）优先，作为其他卷的引用底稿（安装 / UI / 术语先定）。
- 第 37 章真题索引滚动维护（与夸克网盘同步）。
