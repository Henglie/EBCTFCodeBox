# EBCTFCodeBox 全解说明书 · 立项书

> 分支项目 · 状态：**已立项（骨架就绪）** · 立项日期：2026-10-14
> 主项目：恒烈 CTF 编码工具箱（EBCTFCodeBox，当前 v0.1.10）

---

## 一、项目定位

为「恒烈 CTF 编码工具箱」编写一部**全解说明书**：从选择与启动，到每个分区、每个
op 的详细讲解与真实使用案例，再到设计理念与问答，一册到底。

- **目标读者**：CTF 选手（入门到进阶）、密码学学习者、把本工具当日常工具箱的用户。
- **发布形态**：**PDF**（终稿交付物）。
- **编辑形态**：**Markdown 源文件**（本目录）。理由：纯文本便于版本管理、diff、AI 协作与
  多端同步；排版期再统一转 PDF（可选 docx 中间稿由排版需要决定，不作为主源）。
- **案例存储**：真题原卷 / 附件走**夸克网盘**（恒烈维护），说明书中只放**题名 + 考点 +
  解题过程 + 网盘索引位**，不内嵌大文件。

## 三、写作工作流（每批）

1. **取数**：以 registry 真实 op 为准（`node 工具/rt_t185_opcount.mjs` 对数），逐 op 撰写，
   严禁凭印象编造参数与行为。
2. **取证**：每个 op 条目的示例必须实机可复现（或 Node 侧 KAT 证据）；真题案例注明来源与
   考点，附件索引指向夸克网盘。
3. **分批评审**：按分类批次交付，恒烈评审后合并；修订记录进 git。
4. **排版**：终版按卷导出 PDF（目录、页码、索引）；PDF 生成脚本拟用 Markdown → HTML → PDF
   管线（服务器/本机均可，具体工具选定后补记）。

## 四、真题案例工作流

- 来源：公开 CTF 赛事真题、题库平台（如 BUUCTF / CTFHub / NSSCTF 等）中的**编码与密码类**题目；
  优先选**能用本工具直接或串联解决**的题。
- 每道题的说明包：题名（赛事/平台 + 年份）→ 考点 → 对应 op → 解题过程（截图或文字步骤）→
  原卷/附件在夸克网盘的索引位。
- **红线**：不伪造题目；未核实来源的题不标注"真题"；尊重原题版权，只做教学引用。
